# ethira CLI site

Astro + Tailwind marketing site and docs, deployed to GitHub Pages at
[ethira-dev.github.io/cli](https://ethira-dev.github.io/cli/).

```bash
just site-dev     # http://localhost:4321/cli/
just site-build   # output -> site/dist
```

Or from this directory:

```bash
npm install
npm run dev
npm run build
```
