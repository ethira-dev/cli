# Trademarks

“Ethira”, the Ethira wordmark, and the Ethira logo (including the SVG mark used
in the OAuth callback UI) are trademarks of Ethira AB.

Brand guidelines: <https://ethira.dev/brand>

## Allowed

- Factual statements that software “works with Ethira” or “is compatible with
  the Ethira API”.
- Referring to this repository as the official Ethira CLI when redistributing
  unmodified releases published by Ethira.

## Not allowed

- Using the Ethira name, logo, or wordmark in a way that implies an unofficial
  fork, mirror, or modified binary is the official Ethira CLI.
- Using Ethira branding for marketing that suggests endorsement without written
  permission.

## Forks and modified builds

If you distribute a modified build, rename the crate, binary, and user-visible
branding so users are not confused. Do not reuse the Ethira logo or OAuth
callback branding without permission.

For brand questions, contact hello@ethira.dev.
